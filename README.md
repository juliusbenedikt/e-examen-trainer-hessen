# E-Examen Trainer Hessen

Übungsprogramm für das **E-Examen im 2. juristischen Staatsexamen (Assessorexamen) in Hessen**. Es bildet den Arbeitsablauf der elektronischen Examensklausur nach, damit Übungsklausuren unter examensnahen Bedingungen am Rechner geschrieben werden können – offline und ohne Installation.

**[▶ Direkt im Browser öffnen](https://juliusbenedikt.github.io/e-examen-trainer-hessen/)** · **[⬇ Als Datei herunterladen](https://github.com/juliusbenedikt/e-examen-trainer-hessen/releases/latest)**

## Funktionen

- Countdown mit frei wählbarer Bearbeitungszeit, Pause-Bildschirm, Hinweise vor Ablauf
- Formate „Kopfzeile“ und „Absatz“, Blocksatz als Standard, Hervorhebungen, Listen, Tabellen, Sonderzeichen
- Geschütztes Leerzeichen (Knopf, ⌥/Alt+Leertaste oder Strg+Umschalt+Leertaste)
- Vorschau und Druck im Klausurformat: A4, Kopfzeile mit Kennziffer, Titel und Seitenzahl, Korrekturrand rechts
- Export als PDF (über Drucken), Word und HTML
- Speichern wie in Word: Eine Klausur ist eine Datei. Sie öffnet sich per Doppelklick direkt zum Weiterschreiben. In Chrome/Edge wird automatisch hineingespeichert, zusätzlich laufend im Browser. Frühere Fassungen werden alle 2 Minuten angelegt.
- Nach dem Beenden weiterschreiben (mit Überzeit-Anzeige)
- Titel und Kennziffer lassen sich nach dem Beenden noch ändern

## Nutzung

**Ohne Installation:** Die Datei herunterladen und per Doppelklick öffnen. Läuft auf macOS, Windows und Linux in jedem aktuellen Browser, vollständig offline.

**Als App:** Die Online-Version in Chrome oder Edge öffnen und in der Adressleiste auf „Installieren“ klicken. Danach startet der E-Examen Trainer wie ein Programm und funktioniert auch ohne Internet.

Empfohlen ist Chrome oder Edge: Nur dort kann das Programm selbstständig in die Klausur-Datei speichern. In Safari und Firefox sichert der Knopf „Als Datei sichern“ den aktuellen Stand als Datei.

## Läuft vollständig auf dem eigenen Rechner

Das Programm ist eine einzelne HTML-Datei, die ausschließlich im eigenen Browser ausgeführt wird. Es gibt keinen Server, kein Benutzerkonto, keine Analyse- oder Tracking-Dienste. Alle Texte bleiben auf dem eigenen Gerät – im Speicher des Browsers und in den Dateien, die man selbst anlegt. Auch die Online-Version lädt nur das Programm herunter; Klausurtexte werden nie übertragen.

## Ein Vibe-Coding-Projekt

Der E-Examen Trainer ist ein privates Vibe-Coding-Projekt: Er ist nicht von einem professionellen Softwareentwickler geschrieben, sondern im Dialog mit einer KI (Claude von Anthropic) entstanden – aus dem Wunsch eines Rechtsreferendars, das E-Examen realistisch üben zu können. Der Code ist entsprechend pragmatisch, wurde aber getestet und im eigenen Examenstraining eingesetzt.
